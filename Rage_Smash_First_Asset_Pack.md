## Purpose
This file lists the FIRST 20 assets to acquire from Sketchfab (or similar sources)
with clear search terms and instructions.

Claude Code should use this as a reference for:

---

# HOW TO USE

1. Go to Sketchfab
2. Copy the search term
3. Apply filters:
   - Downloadable
   - GLTF/GLB
4. Choose a model that fits checklist rules
5. Download and place in correct folder
6. Rename using naming convention below
